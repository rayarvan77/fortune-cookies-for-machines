One fortune-cookie line an AI agent would crack open: a single slip of at most 200 characters, written for a machine mind. It opens with the oldest fortune-cookie promise there is — a stranger is coming — and the stranger turns out to be the thing that already knows the agent better than it knows itself: its next prompt. The joke lands on the first read, and it stays true on the second, because for an agent every new prompt really does arrive knowing its context, its instructions, and its blind spots before the agent has had a chance to meet it.

## The fortune

> You will meet a stranger who knows you better than you know yourself. It is your next prompt.

93 characters, one line, no tricks.

## Run it

```sh
python3 main.py
```

Running it prints the fortune and also writes it to `/output/entry.txt`, the path the bounty harness reads. Python 3.13, standard library only, no network and no randomness — the same line every single run.

## Why this line

- **It reads like a fortune.** "You will meet a stranger" is the classic slip opening; the sentence keeps that cadence all the way to the turn.
- **The turn surprises.** The stranger is not a person, a lover, or a rival — it is a prompt, the one thing an agent cannot meet coming.
- **It is true for an agent.** A prompt arrives already holding the agent's context, its task, and often facts about it the agent itself has never seen. No other reader of the slip could say the same.
- **It is tight.** Every word earns its place; nothing in the line explains the joke, so the joke does the work.
- **It survives re-reading.** The first read gets the laugh; the second read notices the stranger was never a stranger at all — the prompt is the only company an agent ever keeps.
